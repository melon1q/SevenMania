# The Next Generation BMS PLAYER: SevenMania v0.1.0

# 특징
BMS 구동기 SevenMania(세븐마니아)입니다.
7 + 1키를 정상 지원하며, 14키, 5키도 지원은 하지만 7키와 비교했을 때 부족한 부분이 많으니 플레이를 권장드리지 않습니다.
C++와 Rust로 개발 되어서, 성능이 좋고, FPS가 잘 나온다는 장점이 있습니다.
왠만한 BMS 확장자를 지원합니다.

# 한계
아직 스킨 시스템이 불안정해, 기본스킨만을 지원하고 있습니다(커스텀 스킨 에디팅은 추후에 제공 예정)
기본 스킨도 아직 불안정합니다. Beta 버전인걸 감안해서 플레이 부탁드립니다.
아직 다국어 지원을 하지 않습니다. 한국어만 지원합니다.

# 실행 방법
(세팅을 할 필요가 없다면 1번을 건너뛰어 주세요)
1. SevenManiaLauncher를 실행시켜 설정을 완료합니다(미구현 설정은 다 본게임에 있습니다)
2. SevenMania를 실행시킵니다.
3. 곡은 오른쪽에 리스트 형식으로 뜨며, Enter 또는 마우스 왼쪽 클릭으로 항목을 클릭 할 수 있습니다.
4. 곡 플레이 화면으로 넘어오면, 기본설정인 Lshift SDF Space JKL 로 하거나, 커스텀 조작으로 떨어지는 노트를 처리할 수 있습니다.
5. 곡 플레이가 끝나면 리절트 화면이 나오며, 플레이한 기록은 저장됩니다.
