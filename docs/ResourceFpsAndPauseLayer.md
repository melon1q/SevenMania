# 일시정지 판정 레이어 및 자원 표시 FPS

- GPU 플레이에서는 판정·콤보를 기존처럼 게임 사물 위에 그린다. 일시정지
  중에는 이 전경 패스를 메뉴보다 앞 순서에 그려, 메뉴가 판정을 덮도록 한다.
  CPU 렌더링의 기존 메뉴 순서는 유지한다.
- 시스템 자원 보기를 켜면 오른쪽 위 CPU·메모리·GPU 표시 아래에
  `FPS NOW`, `FPS AVG`, `FPS 1% LOW`를 표시한다. 통계 준비 전에는 `--`다.
- 현재 FPS는 약 0.25초 구간의 렌더링 횟수/시간, 평균은 현재 화면 진입 또는
  곡 재시작 이후의 누적 렌더링 횟수/시간이다. 1% Low는 최근 10초의 느린
  프레임 1% 평균 시간을 FPS로 환산한다. 최대 32768개 간격을 보관한다.
- 메뉴·플레이·리절트 전환 및 곡 시작/재시작에서 통계를 초기화한다.
  일시정지와 로딩 시간은 계산에서 제외하고, 일시정지 중에는 직전 값을 유지한다.
- 일반 빌드에서 자원 표시를 끄면 FPS 수집·표시를 중지한다. 진단 전용 빌드는
  기존 FPS 경보 검증을 위해 수집을 계속할 수 있다.
- 렌더링을 수행한 WM_PAINT마다 한 번 기록한다. GPU 출력 허가를 기다리다
  그리지 않은 프레임이나 GPU 실패 후 같은 프레임을 CPU로 다시 그린 경우를
  추가 집계하지 않는다. 모니터 주사율이나 실제 출력 FPS와는 구분된다.
- 프레임 간격 기록은 할당 없이 수행하고, 느린 1% 계산은 초당 최대 한 번이다.
- GPU 모드의 자원 글자는 기존 텍스트 캐시를 통해 직접 출력하므로, 스킨이나
  연습 모드의 CPU 업로드 영역 높이 때문에 마지막 FPS 줄이 잘리지 않는다.

검증: 기본 Release 빌드 성공. `BmsFrameStatisticsTests`와
`SevenManiaSkinApplicationTests` 122개 검증 통과. GPU 캡처에서 일시정지 시
판정이 메뉴 표면 아래에 위치하고 재개 시 전경으로 복구되는 것을 확인했다.
일반 빌드의 수집, FPS 글자 출력, 일시정지/로딩 제외, 화면 전환 초기화,
비활성화 시 숨김도 확인했다. `Validation/SkinApplication/resource-fps.png`의
1000 FPS는 1ms 간격을 입력한 표시 테스트 값이며 실측 성능 수치가 아니다.

기본 실행 파일은 `build-rmlui-song-list/Release/BmsPlayer.exe`이며 기존 사용자
스킨은 변경하지 않았다. 실제 게임 창을 통한 수동 플레이 검증은 별도로 수행하지 않았다.
