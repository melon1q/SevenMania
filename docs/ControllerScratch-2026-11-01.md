# 컨트롤러 자동 해제 및 스크래치 반복 입력 수정

- 회전축이 감도 기준을 넘을 때마다 `scratchPulse`를 발생시키고, 이미 누른
  스크래치를 해제/재입력하던 경로가 반복 키음의 원인이었다.
- 이제 같은 방향으로 계속 회전하는 동안은 한 번 누른 상태를 유지한다.
  정지해 설정된 스크래치 유지시간이 지난 뒤 다시 회전하거나, 반대 방향으로
  감도 기준 이상 움직일 때 새 입력을 한 번 발생시킨다. 장노트 유지와 키보드
  입력 합성 규칙은 그대로다. 실제 360도 회전 수를 세는 기능은 아니다.
- DirectInput 버퍼를 먼저 읽고 마지막 장치 상태를 그 다음 읽는다. 더 오래된
  축 상태를 최신 버퍼 이벤트 뒤에 적용하여 가짜 역회전이 생기는 것을 막는다.
- 시작 시, 장치 연결을 잃었을 때, 설정 저장 시 대상 장치를 찾지 못하면
  사용 옵션을 해제한다. 자동 선택 모드는 연결된 게임 컨트롤러가 하나라도
  있으면 유효하고, 지정 GUID 모드는 해당 장치가 있어야 한다.
- 자동 해제는 `Controller/Enabled=0`으로 저장하고 폴링 타이머를 1초로
  낮춘다. 장치 ID·버튼·감도 설정은 지우지 않는다. 일시적인 포커스 상실이나
  장치 획득 실패만으로 장치가 없다고 판단하지 않는다.

검증: 연속 회전·축 래핑·동일 시각 버퍼·1/4/16ms 간격·역회전·정지 후
재입력·포커스/연결 전환·키보드 합성·네이티브 설정 저장/취소를 검증했다.
존재하지 않는 GUID는 실제 DirectInput 장치 열거·poll 경로에서도 자동 해제된다.
기본 `BmsPlayer.exe`를 별도 INI로 실행하여 Enabled=1인 없는 장치가 0으로
저장되는 것과 창 표시·정상 종료(exit 0)를 확인했다.

실제 IIDX 컨트롤러를 직접 돌리는 하드웨어 테스트는 수행하지 못했다.
검증 산출물: `build-rmlui-song-list/Validation/ControllerGesture/`.
