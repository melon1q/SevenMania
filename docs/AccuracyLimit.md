# F5 재시작 및 정확도 제한

플레이 중 **F5**로 곡을 즉시 재시작한다. 일시정지 중에도 사용할 수 있으며,
기존 R 재시작은 유지한다. 곡 선택 화면의 F5 다시 검색 기능은 그대로다.
F5를 길게 눌러도 키 반복으로 재시작이 연속 실행되지 않는다.

설정의 **요약**, **게임플레이** 탭에서 **정확도 제한**을 선택한다.
두 탭은 같은 값을 사용하고 다음 실행에도 유지된다. 기본값은 **없음**이다.

| 설정 | 자동 재시작하는 판정 |
|---|---|
| 없음 | 없음 |
| PGREAT 미만 | GREAT, GOOD, BAD, POOR |
| GREAT 미만 | GOOD, BAD, POOR |
| GOOD 미만 | BAD, POOR |
| BAD 미만 | POOR |

기준과 같은 판정은 허용한다. 화면에서 PGREAT을 GREAT 글자와 색 변화로
표현하더라도, 내부의 실제 판정 등급으로 비교한다. 놓친 노트와 롱노트
시작·종료 판정도 같은 경로로 처리한다. 별도 지뢰 데미지 이벤트를 새로운
판정 등급으로 환산하거나 기존 점수·게이지 계산 규칙을 바꾸지는 않는다.

판정 중에는 재시작 요청만 남기고, 현재 입력·노트 순회가 끝난 뒤 UI 메시지로
기존 재시작 경로를 실행한다. 중복 요청을 합치며, 곡 전환·재시작·설정 변경
이전의 오래된 요청은 무시한다. 기준 미달 판정과 HARD 게이지 소진이 동시에
일어나면 자동 재시작을 우선해 실패 리절트로 넘어가지 않는다.

재시작 시 오디오와 BGA 시간을 되돌리고 점수·콤보·게이지·노트·입력 상태를
기존 방식으로 초기화한다. 연습 모드는 선택한 구간 시작점으로 돌아간다.
연습 시작점 이전 노트는 입력/놓침 판정에서 제외해, 그 노트 때문에
자동 재시작이 반복되지 않도록 했다. 키보드 반복 입력도 새 노트 입력으로
취급하지 않는다. F5는 레인 지정에서 제외하고, 기존 m-sudden의 F5 가드
리셋보다 재시작을 우선한다. F3/F4 가드 조절은 유지한다.

저장: `[Gameplay] AccuracyLimit=0..4`.

검증: 기본 Release 빌드 성공. 실제 무음 WAV와 WASAPI 재생을 사용한
F5·자동 재시작·판정 경계·롱노트·HARD 실패 우선 처리·구간 재시작·설정 저장
및 두 UI 동기화 테스트, 기존 설정 컨트롤러·3단계·5단계 회귀 테스트 통과.
실제 곡 전체를 수동 플레이하는 검증은 별도로 수행하지 않았다.
