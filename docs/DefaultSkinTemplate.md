# 기본 외형 참고 템플릿

파일: Assets/Skins/DefaultReference.semaskin
에디터에서 새 스킨 → 예: 기본 외형 참고 / 아니요: 빈 스킨 / 취소: 현재 문서 유지.
저장하지 않은 변경 버리기 확인은 기존 방식으로 먼저 진행한다.

사용자가 선택한 범위에 따라 완전한 네이티브 UI 변환이 아닌 편집 가능한 외형 참고 템플릿이다. 1920×1080 곡 선택의 기본 정보 배치, 슬롯 이미지와 라벨, 리절트의 제목·난이도·작곡가·랭크·점수·클리어 표시를 레이어로 옮겼다. 플레이는 기존 노트/기어를 유지하고 읽기 전용 데이터 기반 표시 레이어를 제공한다. 플레이 참고 HUD는 겹침을 줄이기 위해 우측에 배치했다. 실제 기본 플레이 HUD의 위치를 1:1로 복제한 것은 아니다.

hud-icon-slot.png, turntable.png, whitebutton.png, blackbutton.png는 기존 파일의 사본을 패키지에 넣었다. 원본은 수정하지 않았다. 디스크/건반 이미지는 제작자가 배치할 수 있는 자원으로 들어 있으며 자동으로 원래 기어를 교체하지 않는다.
곡 제목·작곡가·BPM·난이도·점수·콤보·게이지·판정·랭크·클리어 상태는 현재 지원되는 바인딩을 사용한다. 장르·슬롯의 배속/판정 설정/게이지 모드는 해당 바인딩이 없어 편집 가능한 참고 문자열이다. 동적 장르나 현재 사용자 설정과 자동 동기화한다고 주장하지 않는다. 색상별 난이도 자동 Tint, 결과 배경 블러, 동적 곡 배너, 폰트 외형/그림자와 네이티브 조작까지 동일하게 변환하지 않았다.

새 템플릿 문서는 별도 user.skin ID와 이름으로 시작하며 원본 템플릿 경로를 저장 대상으로 삼지 않는다. 템플릿은 실행 파일 옆 Assets/Skins에서 로딩한다. 파일이 없거나 손상되면 오류를 표시하고 이전 문서를 유지한다.

재생성: tools/CreateDefaultSkinTemplate.py (Python 표준 라이브러리, 게임/에디터 사용에는 불필요).
검증: 에디터 빌드, 템플릿/빈 문서/취소/템플릿 저장·재로드 스모크 통과. 3개 화면 실제 GPU 미리보기 통과. 실제 플레이 전체의 수동 외형 비교는 수행하지 않았다.
