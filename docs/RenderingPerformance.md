# FREEDOM DiVE 렌더링 최적화 — 2026-10-11

사용자 설정은 무제한 FPS, DirectComposition 켜짐, 배속 6.00x, BGA 밝기 20%, 레인 투명도 0%, 왼쪽 기어였다. 230 FPS 증상은 설정의 240 FPS 제한으로 설명되지 않는다. 실제 FREEDOM DiVE [ANOTHER 7]의 BGA와 노트를 사용해 원인을 분리했다.

## 측정 조건과 결과

1920×1080 클라이언트, 실제 글꼴·턴테이블·HUD 리소스, 3~19초 채보 구간의 240개 화면을 검사했다. BGA 변경 부하를 재현하려고 채보 시각을 프레임당 1/15초씩 진행했다. 실제 오디오 재생 FPS와 다른 렌더링 부하 검사이며, 아래 수치를 게임의 최종 FPS로 해석하면 안 된다. 비교 기준 소스는 `4242454`다. 개인 곡·원시 CSV·기준 실행 파일은 Git과 배포 ZIP에 포함하지 않는다.

| 조건 | 수정 전 평균 프레임 시간 | 수정 후 평균 프레임 시간 |
|---|---:|---:|
| 일반 BGA, 콤보·판정 표시 | 8.53ms | 1.89ms |
| 불투명 전체 화면 미스 레이어, 콤보·판정 표시 | 11.79ms | 0.55ms |
| 위 미스 조건 + DirectComposition 출력 | 11.36ms | 2.27ms |

일반/미스 렌더링 값은 세 번 실행한 평균값들의 중앙값이다. DirectComposition은 장치·스왑체인 최초 생성까지 포함한 한 번의 비교다. 동시에 실행 중인 앱과 GPU 부하에 따라 시간이 달라진다.

수정 전 미스 조건의 텍스트·건반 HUD 비용은 약 4.10ms였고, 수정 후 약 0.36ms였다. 가려진 BGA 변경 때문에 배경을 재합성한 횟수는 240개 화면 중 237회에서 1회로 줄었다. 일반 BGA는 계속 237회 합성되므로 애니메이션을 생략해서 얻은 개선이 아니다.

90초 이후 구간에서 모든 레인의 키 빔·건반 입력, 히트 스플래시, 매 프레임 새로운 콤보 숫자와 확대 애니메이션을 강제로 발생시킨 추가 검사는 평균 1.83ms였다. 실제 플레이보다 빈번한 HUD 변경을 주는 검사다.

## 유지한 기능과 줄인 작업

- 굵은 판정/콤보 윤곽선의 24개 오프셋과 색은 유지한다. 글자 원본을 GDI로 만든 후 윤곽선을 픽셀로 합성하고, 최대 8개 텍스트 이미지를 재사용한다. easeOutBack 애니메이션은 같은 이미지를 부드럽게 확대한다. 캐시 생성 실패 시 기존 GDI 출력으로 돌아간다.
- 미스 레이어를 유지한다. 불투명하고 화면 전체를 덮는 이미지일 때만 아래 이미지·영상을 합성에서 제외한다. 투명하거나 일부 영역만 가리면 아래 BGA도 계속 갱신한다. 미스가 끝나면 현재 시각의 BGA를 복원한다.
- BGA 밝기와 레인 투명도를 유지한다. 검은 음영은 SSE2로 처리하며, 완전 불투명 색은 직접 채우고 투명도 0인 연산은 건너뛴다.
- 건반과 회전 턴테이블을 유지한다. 픽셀마다 레인을 다시 탐색하지 않고, 원판 테두리는 제곱 거리로 판별한다. 기준 건반 이미지와 수정 후 이미지의 해시가 동일했다.
- 확대 BGA 캐시 상한을 128MiB에서 256MiB로 늘렸다. 1080p 이미지의 반복 확대와 캐시 교체가 줄어든다. 필요한 이미지만 저장하며 원본 캐시 상한은 계속 64MiB다. 최대 추가 메모리는 128MiB다.

기능 삭제가 필요할 만큼 비싼 부가 기능은 발견되지 않았다. 효과음 볼륨 설정은 아직 추가 예정인 항목이며 렌더링 병목과 관계가 없다. DirectComposition 출력 자체도 GPU 업로드/프레젠트 비용이 있으므로 렌더링을 빠르게 해도 최종 FPS가 화면·GPU 환경에 무관하게 무한히 증가하지는 않는다.

## 검증

텍스트 캐시 재사용·색·배경 투명성·화면 밖 클리핑·확대 중심, 투명 미스 아래 BGA 변경, 불투명 미스 최적화, 미스 종료 복원, BGA 색과 확대·자르기, SIMD와 독립적인 스칼라 음영 결과 일치, 건반 이미지 동일성, 게임오버·리절트, 키 입력·설정·목록 UI를 검사했다. 실행 방법은 다음과 같다.

```powershell
cmake --build build-turntable --config Release --target BmsRenderTests
build-turntable/Release/BmsRenderTests.exe "<채보.bme>" "<측정.csv>" 6 3 on steady "<설정.ini>"
```

`on` 대신 `off`로 미스 레이어를 끌 수 있으며, `steady` 대신 `animated` 또는 `effects`로 확대/입력 효과 부하를 줄 수 있다. 마지막에 `compose` 또는 `gdi`를 추가하면 실제 출력도 측정한다. 외부 설정 파일은 읽기만 하며 곡을 복사하거나 수정하지 않는다.
