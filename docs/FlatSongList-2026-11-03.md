# 곡 리스트 단색 스타일·이동음 분리·런처 종료

- 일반 곡 바는 은색 단색 `#bcc2c9`, 선택 바는 밝은 은색 `#dce2e8`로 변경했다. 모서리는 직각이며 그라데이션 decorator를 제거했다.
- 일반 항목의 왼쪽 경계는 20px, 선택 항목은 4px로 두어 선택 바가 왼쪽으로 정확히 16px 돌출된다. 오른쪽 경계는 동일하며 뷰포트 밖으로 잘리지 않는다.
- 폴더/상위 이동 바도 단색이다. 상위 이동은 기존 청회색 계열을 유지한다. 밝은 바에서 읽히도록 기본/선택 글자색은 어두운 색으로 조정했다. 배너와 난이도별 색은 유지한다.
- RmlUi 외에 네이티브 대체 표시 경로도 직사각형·단색·16px 돌출로 맞췄다.
- 위/아래·휠·반복 이동은 `songlistscroll` 효과 ID, 클릭/Enter 확정은 기존 `click` ID로 분리했다. 차분 변경의 기존 levelchange 효과는 유지했다.
- 사용자가 이동음 파일을 준비 중이라고 확인했으므로 가짜 음원은 만들지 않았다. 실제 실행 폴더의 `Assets/songlistscroll.mp3`를 시작 시 읽고, 없으면 이동음은 무음이다. 파일을 넣은 뒤 게임을 다시 실행하면 적용된다. 선택/확정음 `Assets/click.mp3`는 계속 사용한다. 매 스크롤마다 파일을 확인하거나 디코딩하지 않는다.
- 소스 Assets에 음원이 있을 때 복사하는 선택적 빌드 스크립트를 추가했다. 누락된 음원 때문에 빌드가 실패하지 않으며 기존 사용자가 실행 폴더에 넣은 파일을 지우지 않는다.
- 런처의 WM_CLOSE 확인창을 제거했다. 기존 취소/join/핸들 정리는 유지하고, 런처를 닫아도 게임은 종료하지 않는다. 적용하지 않은 설정을 자동 저장하지는 않는다.

## 검증

Release 게임(BmsPlayer.exe/SevenMania.exe)과 SevenManiaLauncher.exe 업데이트 성공.

BmsRmlSongListTests, BmsRmlSongListHostTests, SevenManiaLauncherUiTests 3/3 통과. 실제 픽셀 검사에서 일반/선택 경계 20px/4px, 직각 모서리, 일반/상위/선택 배경의 세로 방향 단색을 확인했다. normal/selected PNG 캡처도 열어 확인했다. 기존 텍스트 스크롤·선택·크기 변경·캐시 재그리기 검사를 유지했다.

런처 통합 테스트는 직접 WM_CLOSE를 보내 확인창 없이 창이 사라지고 실행한 게임이 계속 살아 있는지 확인했다. 테스트 게임은 기존 게임 종료 확인창에 정상 응답해 닫았다.

이동음 파일은 없으므로 실제 음원의 청감 검증은 수행하지 않았다. 음향 엔진은 재작성하지 않았으며 기존 캐시/triggerEffect 경로를 재사용한다.

로그/화면: `build-rmlui-song-list/Validation/flat-list-*.log`, `Validation/RmlUi/entry-*-normal.png`, `entry-*-selected.png`. 빌드 산출물과 캡처는 커밋하지 않는다.
