# 플레이 기어 스킨 연결

DefaultReference의 play 화면에서 건반, 턴테이블/테두리, 게이지, 슬롯을 개별 레이어로 편집할 수 있습니다. extensions.nativeGearPart 요소는 플레이 중 실제 기어 중앙과 판정선을 기준으로 이동합니다. 기본 좌표 기준은 1920x1080, 중앙 X=960, 판정선 Y=720입니다. 기어 크기는 기존 게임처럼 실제 픽셀 크기를 유지합니다.

7+1키 플레이에서는 이 스킨 레이어를 구동기가 직접 렌더링하고, 건반 눌림, 턴테이블 회전, 게이지, 배속을 읽기 전용으로 전달합니다. nativeGearPart 및 기본 요소 ID를 유지해야 상태 연결이 유지됩니다. 5K, 10K, 14K, PMS 9K는 같은 요소에 `extensions.gearModes`로 저장된 모드별 배치를 사용합니다(아래 "키 모드별 기어"). 스킨에 해당 모드의 배치가 없으면 7K 기어 요소는 숨기고 기존 게임 기어만 보입니다.

레인 배경/구분선/키 가이드는 editorOnly 참고 레이어이며 실제 노트 경로는 기존 게임 렌더러가 담당합니다. 하단 스킨은 기존 하단 표시 위에 그려집니다. 전체 기어 렌더러의 제거 또는 모든 모드의 완전한 스킨 전환은 이 변경에 포함되어 있지 않습니다.

## 위치별 배치

에디터의 play 화면 하단에서 기어 왼쪽/가운데/오른쪽을 선택합니다. 각 위치에서 사물을 움직인 뒤 저장하면 extensions.gearLayouts.left/center/right의 x,y로 보관됩니다. 에디터에서 다른 위치로 전환할 때마다 현재 배치를 재사용할지 예/아니요/취소를 묻습니다. 예는 현재 배치를 대상 위치에 복사하고 기존 배치를 덮어씁니다. 기어 오브젝트는 기어의 이동량만큼 이동하며 주변 UI는 현재 위치를 유지합니다. 아니요는 대상 위치의 저장값을 사용합니다. 좌우 직접 전환에서 예를 고르면 주변 UI 위치도 좌우 반전할지 추가로 묻습니다. 같은 위치를 다시 누르면 아무 작업도 하지 않습니다. 반전은 x = 화면 너비 - x - 사물 너비이며 텍스처나 글자의 방향은 유지됩니다.

게임 설정에서 기어 위치를 좌우로 전환할 때도 같은 반전 여부를 묻습니다. 반전 선택은 현재 실행 중 적용되며, 위치별 편집 좌표 자체는 스킨 패키지에 저장됩니다. 위치별로 독립 보관되는 속성은 x,y이며 크기와 스타일은 공통입니다.

## 키 모드별 기어

기어 요소(`nativeGearPart`)는 7K 배치를 기본값으로 가지며, 5K·10K·14K·PMS는 요소마다 `extensions.gearModes.<5k|10k|14k|pms>`에 `{x, y, width, height, visible}`로 저장합니다. 좌표는 기본 배치와 같이 기어 중심 X=342(왼쪽 위치)를 기준으로 하며, 위치별 이동량(`gearLayouts`)은 모드와 무관하게 그대로 적용됩니다. 게이지 채움 요소는 `fullWidth`(게이지 100%일 때 폭)를 추가로 가집니다. 모드별 값이 있으면 런타임이 그 값으로 위치·크기·표시 여부를 바꿔 그리고, 7K에서는 `gearModes`를 읽지 않습니다.

- 건반 이미지는 7K의 `white-key`/`black-key` 리소스를 그대로 씁니다. 1P는 `gear-key-1~7`, 2P는 `gear-key-p2-1~7`, 2P 스크래치는 `gear-scratch-rim-p2`/`gear-scratch-disc-p2`이며 눌림·회전 연결은 요소 ID로 합니다(`src/skin/GearMode.h`의 `gearKeyLane`). PMS는 1P 건반 7개와 `gear-key-p2-2`(검은 건반), `gear-key-p2-3`(흰 건반)을 레인 0-6, 7, 8에 씁니다.
- DP의 2P 스크래치는 오른쪽 끝(`SC 1-7 | 1-7 SC`)입니다. 키 가이드 텍스트(`gear-key-guide-N`, 2P는 `gear-key-guide-p2-N`)는 레인을 따라가며, 게임이 플레이 중 그 레인에 지정된 키 이름(`SkinGearState.keyLabels`)으로 항상 채웁니다. 7K 포함 모든 모드에서 스킨에 적힌 글자는 무시되고, 키 설정을 바꾸면 곧바로 반영됩니다. 스킨에 가이드 요소가 있으면 게임 자체의 초반 2초 키 표시는 그리지 않습니다.
- 에디터 play 화면의 `기어 7K / 5K / 10K / 14K / PMS` 버튼으로 편집할 모드를 고릅니다. 모드를 바꾸면 기어 요소가 그 모드의 배치로 바뀌고, 저장하면 7K 배치는 기본 위치에, 나머지는 `gearModes`에 기록됩니다. `기어 왼쪽/가운데/오른쪽` 전환은 7K 모드에서만 할 수 있습니다.
- 기본 스킨의 모드별 값은 `tools/generate-gear-modes.py`가 만듭니다. 레인 폭은 게임의 `LaneLayout`(DP는 건반 45/스크래치 68)과 같게 맞춥니다.

```powershell
python tools/generate-gear-modes.py Assets/Skins/DefaultSkin/DefaultReference.semaskin
```
