# 플레이 기어 스킨 연결

DefaultReference의 play 화면에서 건반, 턴테이블/테두리, 게이지, 슬롯을 개별 레이어로 편집할 수 있습니다. extensions.nativeGearPart 요소는 플레이 중 실제 기어 중앙과 판정선을 기준으로 이동합니다. 기본 좌표 기준은 1920x1080, 중앙 X=960, 판정선 Y=720입니다. 기어 크기는 기존 게임처럼 실제 픽셀 크기를 유지합니다.

7+1키 플레이에서는 이 스킨 레이어를 구동기가 직접 렌더링하고, 건반 눌림, 턴테이블 회전, 게이지, 배속을 읽기 전용으로 전달합니다. nativeGearPart 및 기본 요소 ID를 유지해야 상태 연결이 유지됩니다. 다른 키 모드는 기존 게임 기어를 사용합니다.

레인 배경/구분선/키 가이드는 editorOnly 참고 레이어이며 실제 노트 경로는 기존 게임 렌더러가 담당합니다. 하단 스킨은 기존 하단 표시 위에 그려집니다. 전체 기어 렌더러의 제거 또는 모든 모드의 완전한 스킨 전환은 이 변경에 포함되어 있지 않습니다.

## 위치별 배치

에디터의 play 화면 하단에서 기어 왼쪽/가운데/오른쪽을 선택합니다. 각 위치에서 사물을 움직인 뒤 저장하면 extensions.gearLayouts.left/center/right의 x,y로 보관됩니다. 에디터에서 다른 위치로 전환할 때마다 현재 배치를 재사용할지 예/아니요/취소를 묻습니다. 예는 현재 배치를 대상 위치에 복사하고 기존 배치를 덮어씁니다. 기어 오브젝트는 기어의 이동량만큼 이동하며 주변 UI는 현재 위치를 유지합니다. 아니요는 대상 위치의 저장값을 사용합니다. 좌우 직접 전환에서 예를 고르면 주변 UI 위치도 좌우 반전할지 추가로 묻습니다. 같은 위치를 다시 누르면 아무 작업도 하지 않습니다. 반전은 x = 화면 너비 - x - 사물 너비이며 텍스처나 글자의 방향은 유지됩니다.

게임 설정에서 기어 위치를 좌우로 전환할 때도 같은 반전 여부를 묻습니다. 반전 선택은 현재 실행 중 적용되며, 위치별 편집 좌표 자체는 스킨 패키지에 저장됩니다. 위치별로 독립 보관되는 속성은 x,y이며 크기와 스타일은 공통입니다.
