# 시작 스플래시와 숨겨진 곡 버튼

2026-10-26

## 이미지 교체 규격

- 원본: `Assets/startup-splash.png`. imagegen으로 생성한 교체용 예시 이미지이며 실제 크기는 1672×941이다.
- 권장: 가로 16:9 PNG, 예를 들어 1920×1080. 게임은 다른 해상도도 원본 비율을 유지해 중앙에 맞추며 남는 부분은 어두운 여백으로 채운다.
- 아래쪽 약 20%는 진행률과 상태 문구를 위한 여백으로 두는 편이 좋다. 진행률·로딩 문구는 이미지에 넣지 않고 게임이 그린다.
- 게임은 실행 파일 옆 `Assets/startup-splash.png`를 읽는다. 같은 이름으로 교체한 뒤 재시작하면 적용된다. 소스 파일을 바꾼 경우 다시 빌드하면 실행 폴더에도 복사된다.
- 이미지가 없거나 손상되어 읽히지 않아도 제목과 진행률이 있는 기본 화면으로 계속 시작한다.

## 동작

첫 곡 라이브러리 복사·검색·분석과 곡 목록 구성이 끝날 때까지 메인 창에 스플래시를 표시한다. 목록과 숨겨진 곡 버튼은 가려 두며, 정상 완료 시 곡 선택 화면으로 전환하고 이미지는 메모리에서 해제한다. 초기화가 빠르면 스플래시도 짧게 나타난다. 인위적인 대기 시간은 추가하지 않았다. 이후 F5 재검색과 플레이 시작 로딩에는 부팅 스플래시를 다시 사용하지 않는다.

복사 단계는 진행 바의 0–25%, 채보 분석은 25–100%로 표시한다. 이는 단계별 비율이며 전체 소요 시간을 예측한 값이 아니다. 실패·취소·초기 Songs 폴더 생성 실패 시에도 스플래시를 닫고 곡 선택 화면에 기존 오류/취소 안내를 남긴다. 창 닫기와 검색 취소 입력은 유지한다. 음원 전체를 시작 시 디코딩하는 방식으로 바꾸지는 않았으며, 미리보기 사전 준비는 기존의 비동기 동작을 유지한다.

`playable=false`인 숨겨진 채보가 있을 때만 숨겨진 파일 버튼을 표시한다. 확장자 이외에도 기존 파서가 차단한 채보가 대상이다. 숨겨진 곡 보기에서는 원래 곡 목록으로 돌아가는 버튼을 유지한다. 플레이 가능한 부분 로딩 곡만 있는 경우에는 버튼을 표시하지 않는다.

## 검증

Release 플레이어와 Display/실제 ListView 호스트 테스트로 확인한다. 호스트 테스트는 정상/숨겨진 곡 버튼 표시, 패키징된 이미지 로딩과 그리기, 이미지 누락 시 기본 화면, 초기 로딩 완료/실패/취소 시 화면 복귀를 확인한다. 합성 화면은 빌드 폴더의 `Validation/RmlUi/startup-splash.png`에 저장한다.
