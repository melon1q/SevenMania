# 판정선 아래 전용 아이콘

- 첫 번째 슬롯: `Assets/hud-hi-speed.png`. 사용자가 제공한 `speed.png` 원본을
  그대로 사용하며, 기존 배속 값을 표시한다.
- 두 번째 슬롯: `Assets/hud-gauge-mode.png`. 제공한 `splash-speed.png` 원본을
  그대로 사용한다. 값 영역에는 `NORMAL`, `EASY`, `HARD` 중 현재 설정된 모드명만 표시한다.
- 세 번째·네 번째 빈 슬롯과 곡 선택 화면의 기존 공통 이미지는 유지한다.
- 두 이미지는 게임 에셋과 기본 스킨 패키지에 각각 별도 리소스로 포함한다.
  에디터의 기본 스킨에서도 확인·편집할 수 있다.
- 새 읽기 전용 문자열 바인딩은 `play.gaugeMode`이며 플레이 화면에서만 유효하다.
  에디터 미리보기와 데이터가 없는 경우의 기본값은 `NORMAL`이다.
- 복구한 스킨은 전체 재생성하지 않고 첫 두 이미지, 첫 슬롯의 값 영역,
  두 번째 슬롯의 새 텍스트만 업데이트했다. 나머지 화면과 기존 리소스는 보존했다.
- 기존 패키지를 갱신하는 도구는 `tools/UpdateGearHudIcons.py`이며,
  수정 전 파일을 `build-rmlui-song-list/Validation/GearHudIconBackup/`에 보관한다.

검증: 기본 BmsPlayer와 스킨 에디터 Release 빌드 성공. 스킨 바인딩 테스트
415개(소프트웨어 렌더러 및 실제 하드웨어 GPU 각각), 기존 스킨 적용 테스트
122개, 에디터 스모크 테스트 통과. 세 기어 위치에서 각 모드의 문자열과
렌더링 변경을 확인하고 중앙 배치의 NORMAL/EASY/HARD 화면을 캡처했다.
제공 이미지·배포 이미지·패키지 이미지의 바이트 일치, 기존 곡 선택/리절트
JSON과 다른 리소스 보존도 확인했다. 게임 창에서의 수동 플레이 검증은 수행하지 않았다.
