# BMS Player — 시험 배포판

Windows 10/11 64비트용 7+1키 BMS 플레이어입니다. 곡 파일은 포함되어 있지 않습니다.

## 실행

1. 폴더 전체를 쓰기 가능한 위치에 두고 `BmsPlayer.exe`를 실행하세요.
2. **F2**로 곡 폴더를 선택하세요. 선택한 곡은 실행 파일 옆 `Songs` 폴더에 복사됩니다.
3. 목록에서 곡을 선택하고 **Enter**로 플레이하세요.

`BmsPlayer.exe`와 `Assets` 폴더는 함께 보관해야 합니다. 배포할 때도 이 폴더 전체를 압축해 전달하세요.

## 기본 조작

| 화면 | 키 | 동작 |
| --- | --- | --- |
| 곡 선택 | ↑ / ↓ | 곡 선택 |
| 곡 선택 | ← / → | 같은 곡의 채보 변경 |
| 곡 선택 | Enter / Shift+Enter | 플레이 / 연습 모드 |
| 곡 선택 | Space | 설정 |
| 곡 선택 | F2 / F5 | 곡 폴더 추가 / 다시 검색 |
| 플레이 | 왼쪽 Shift | 스크래치 |
| 플레이 | S D F Space J K L | 1~7번 건반 |
| 플레이 | Esc | 일시정지 |

키 배치·음량·해상도·화면 모드는 설정에서 변경할 수 있습니다. 설정은 변경 즉시 저장됩니다. 새 설정 화면에 문제가 있으면 하단의 **기존 설정창 사용**으로 전환하세요.

설정과 플레이 기록은 `%APPDATA%\BmsPlayer`에 저장됩니다. 이 배포 폴더에는 제작자의 개인 설정·기록·곡을 넣지 않았습니다.

시험 배포판이므로 문제가 발생하면 오류 문구, 곡/채보 이름, 화면 모드와 해상도를 함께 알려주세요. 구성 요소의 라이선스는 `Assets/Licenses`에 있습니다.
