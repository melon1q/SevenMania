# 스킨 표시 박스

에디터의 **빈 박스 +**로 박스를 만든 뒤 `boxMode`에서 `solid`, `title`, `bga`를 선택하고 **속성 적용**을 누릅니다. `solid`는 **색상 선택** 또는 tint.r/g/b로 색을 지정합니다. 드래그와 속성에서 위치·크기·순서를 바꿀 수 있습니다.

`title`은 선택한 채보의 타이틀 이미지, `bga`는 선택 화면의 기존 BGA 미리보기를 사용합니다. 이미지가 없을 때는 회색 배경이 표시됩니다. 실제 이미지 미리보기는 게임의 곡 선택 화면에서 확인할 수 있으며, 에디터에서는 단색으로 표시합니다. 현재 동적 타이틀/BGA 연결은 곡 선택 화면에만 적용됩니다. 색상 박스는 모든 화면에 사용할 수 있습니다.

```json
{"id":"background","type":"box","boxMode":"title","x":0,"y":0,"width":1260,"height":830,"tint":{"r":64,"g":64,"b":64},"z":0}
```

곡 선택 화면의 `song.title` 텍스트가 박스보다 길면 시작과 끝에서 잠시 멈추며 반복해서 이동합니다. 다른 화면의 텍스트 갱신 주기는 변경하지 않습니다.
