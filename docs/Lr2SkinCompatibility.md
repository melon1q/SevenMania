# LR2 스킨 호환 현황

기준: 2026-11-18, `codex/lr2-skin-phase2`. 파서 규칙은 [Lr2SkinPhase1.md](Lr2SkinPhase1.md)에 있다.
이 문서는 "지금 무엇이 그려지고 무엇이 빠지는가"를 기록하며, 단계가 끝날 때마다 갱신한다.

## 범위

- 불러올 수 있는 화면: 7KEY 플레이(type 0), 5KEY 플레이(1), 14KEY 플레이(2), 10KEY 플레이(3), 9KEY 플레이(4), 선곡(5), 결정(6), 결과(7). 다른 type은 파서가 거부한다.
- 스킨은 게임 설정의 "스킨" 페이지에서 화면별로 고른다(아래 "설정 화면"). 명령줄 인자
  `--lr2-play-skin`(7KEY), `--lr2-play5-skin`(5KEY), `--lr2-play14-skin`, `--lr2-play10-skin`, `--lr2-play9-skin`, `--lr2-select-skin`, `--lr2-decide-skin`, `--lr2-result-skin`은 그 실행에만 적용되고
  저장되지 않는다. `--lr2-preview`는 플레이 스킨 전용 단독 미리보기다.
- GPU(컴포지션) 경로가 필요하다. 준비에 실패하면 SevenMania 스킨으로 되돌아간다.
- `CUSTOMOPTION`·`CUSTOMFILE`·`CUSTOMOFFSET`은 스킨별 선택값 파일에서 읽는다(아래 "스킨별 선택값").
  선택값이 없으면 첫 선택지, 기본 파일명, 오프셋 0을 쓴다. 옵션·파일·오프셋 모두 설정 화면에서 고른다
  (오프셋은 스킨이 켠 칸 x·y·w·h·r·a마다 슬라이더 하나, 아래 "설정 화면").

### 옵션 패널

LR2 기본 테마의 패널 1(플레이 옵션)·2(그 밖의 옵션)에 있는 버튼을 SevenMania 설정에 연결한다. 값은 설정 화면과
같은 설정 컨트롤러(`postSetting`)로 바꾸므로 같은 범위 검사를 거쳐 바로 저장된다. 코드는 `src/Lr2SelectHost.inl`의
`pressLr2OptionButton`, 상태와 이름은 `SelectFrame::buttonState`/`optionText`(`src/skin/lr2/Lr2Preview.cpp`)다.

| 버튼 | LR2 의미 | SevenMania 동작 | 칸 / 이름(문자열 ID) |
|---|---|---|---|
| 40 | 1P 게이지 | 노멀 → 하드 → 이지(왼쪽 절반은 역순) | 0 그루브, 1 서바이벌(하드), 3 이지 / 65 `NORMAL`·`HARD`·`EASY` |
| 57 | 1P 하이스피드 | 좌클릭 +0.25, 우클릭 −0.25 (0.5~10). 좌우 절반은 보지 않는다 | 숫자 10 = 배속 × 100 |
| 55 | HS-FIX | HI-SPEED FIX 순환: 끔 → 시작 → 최대 → 주 → 최소 BPM → 일정 (우클릭은 역순) | 칸 = 모드 번호 / 74 `OFF`·`START BPM`·`MAX BPM`·`MAIN BPM`·`MIN BPM`·`CONSTANT` |
| 46 / 50 | 레인 커버 / HID+SUD | 레인 커버 끄기 ↔ 켜기(마지막 값, 처음엔 20%) | 46: 0 끔·1 켬 / 73 `OFF`·`ON`. 50: 0 끔·2 SUDDEN / 84 `OFF`·`SUDDEN` |
| 72 | BGA | BGA 밝기 0 ↔ 마지막 값(처음엔 50) | 0 켬, 2 끔 / 76 `ON`·`OFF` |
| 74 | 판정 타이밍 | 판정 오프셋 ±1ms (−100~100) | 숫자 12 = 오프셋(ms) |
| 75 | 판정 자동 조정 | 끔 ↔ 마지막 모드(처음엔 제안) | 0 끔, 1 켬 / 80 `OFF`·`SUGGEST`·`REALTIME` |
| 70 | 스코어 그래프 | `[LR2Skin] ScoreGraph` 0/1 (플레이 조건 38/39) | 0 끔, 1 켬 / 71 `OFF`·`ON` |
| 11 | 키 모드 필터 | 기존과 같음 | 60 `ALL`·`5KEYS`·`7KEYS`·`10KEYS`·`14KEYS`·`9KEYS` |
| 13 / 14 | 스킨·사운드 / 키 설정 | SevenMania 설정 창을 연다 | |

- 우클릭은 값을 바꾸는 버튼(11, 40, 55, 57, 74)을 반대 방향으로 한 칸 움직인다. 그 밖의 위치에서는 우클릭을 원래대로 넘긴다.
- 클릭 방향은 `SRC_BUTTON`의 마지막 값(LR2 `plusonly`)을 따른다. 1이면 항상 증가, 0이면 왼쪽 절반 감소·오른쪽 절반 증가.
  이전 구현은 이 값을 반대로 읽었다(1을 좌우 분할로). 기본 테마의 버튼 11은 1이라 이제 항상 다음 필터로 넘어간다.
- 패널 값(`SRC_BUTTON`의 panel)이 1 이상이면 그 패널이 열려 있을 때만, −1이면 패널이 닫혀 있을 때만 클릭을 받는다.
- 그림이 없는 버튼(폭·높이 0, 또는 칸을 담을 수 없는 1픽셀 자리표시)과 완전히 투명한 `DST_BUTTON`도 클릭 영역은 유지한다.
  LR2 기본 테마의 옵션 버튼은 대부분 이 형태이고, 상태는 옆의 문자열(옵션 이름)이 보여 준다. 칸이 하나뿐인 그림은 모든 상태에 쓴다.
- 레인 커버·BGA·자동 조정을 끌 때 기억하는 "마지막 값"은 실행 중에만 유지한다. 다시 실행한 뒤 처음 켜면 위 기본값이다.
- 화면 모드(80)는 상태(0 창, 1 전체화면)와 이름(79 `WINDOW`·`BORDERLESS`·`FULLSCREEN`)만 표시한다. 선곡 화면이 그려지는
  중에 창 모드를 바꾸는 경로는 검증하지 않아 설정 화면에서 바꾼다.
- 키 타이머 100~119: 1P 스크래치·건반 1~7(7KEY 키 설정)은 100~107, 2P(14KEY 키 설정의 2P 쪽)는 110~117이다. 누르는 동안
  흐르고 떼면 멈춘다. 레인 키는 선곡 화면의 원래 기능(예: 정렬 키)을 그대로 가지며, 옵션을 바꾸지는 않는다(옵션은 마우스로 바꾼다).

**엔진에 없는 기능**(IR·랭킹·라이벌·이펙터·EQ·코스·배틀·텍스트 보기·리플레이)은 "없음"에 고정한다. 결과 화면의 조건은
위 "결과 화면의 조건", 선곡 화면의 타이머 15/16은 "결정·결과 화면의 시계"에 적었다. 선곡 버튼은 첫 칸("없음")에 고정해 그리고 클릭을 받지 않는다: 텍스트 보기(17), 태그 초기화(18),
리플레이(19), 이펙터·EQ·피치(20~29, 32, 33), 2P·배틀 옵션(41, 43, 45, 51, 58), 어시스트(44), 플립(54),
턴테이블 방향(56), 고스트(71), BGA 크기(73), 리플레이 저장(83), IR(92~96, 210), 도움말 페이지(201~206),
코스·태그 편집(230~234, 240~243, 253, 260~268). 이름은 2P 랜덤·어시스트·플립·고스트(64, 67, 68, 70, 72, 85)가
`OFF`, BGA 크기(75)가 `NORMAL`이다. 턴테이블 방향 이름(69)과 리플레이 이름(81)은 그리지 않는다.

- **레인 옵션(42, 문자열 63)**: 1P 랜덤 옵션. OFF → MIRROR → RANDOM → S-RANDOM을 돈다(우클릭은 반대). LR2의 H-RANDOM·
  ALL-SCR은 없다. 게임 설정 "게임플레이"의 "레인 옵션 (1P)"과 같은 설정(`[Gameplay] LaneOption`)이며 다음 플레이부터 적용된다.
  동작은 [키 모드 지원 현황](KeyModeSupport-2026-11-09.md)의 "레인 옵션"을 본다. 2P 쪽(43, 64)은 OFF에 고정한다.
- **난이도 필터(10)**: 6칸(ALL, BEGINNER, NORMAL, HYPER, ANOTHER, INSANE). 누를 때마다 다음 칸(우클릭은 이전 칸)으로
  바뀌고, 곡 목록에는 그 `#DIFFICULTY`의 채보만 남는다. `#DIFFICULTY`가 없는 채보는 ALL에서만 보인다. 키 모드 필터처럼
  Win32 호스트의 목록 필터이며(C++/Rust 선곡 모델은 모른다) 설정 파일 `[Browse] Difficulty`에 저장된다.
  SevenMania 기본 선곡 화면에는 이 필터를 보여 주는 곳이 없으므로, LR2 스킨에서 ALL이 아닌 값을 두면 기본 화면에서도 걸러진다.
- **타깃(77, 문자열 1)**: MY BEST → RANK AAA → RANK AA → RANK A → DEFAULT를 돈다(우클릭은 반대). 버튼 그림의 칸은
  LR2 순서(0 타깃 없음, 1 MY BEST, 2 AAA, 3 AA, 4 A, 5 DEFAULT, 6~8 IR)를 따른다(WMIX_HD 주석 기준). 칸이 하나뿐인 그림은 늘 그 칸이다. **기본 타깃(76, 숫자 13)**:
  DEFAULT 타깃의 비율(%)을 1씩 바꾼다(0~100, 처음 50). 둘 다 `[Browse] Target`/`TargetRate`에 저장되고 다음 플레이부터
  쓰인다. 계산은 `src/TargetScore.h`.
EQ(10~16)와 피치(26) 슬라이더는 가운데, 이펙터 슬라이더(20~25)는 0에 고정한다. 오토플레이 버튼(16)은 첫 칸으로 그리고,
곡이 선택돼 있을 때 누르면 그 곡을 오토플레이로 시작한다(아래 "오토플레이"). 메인 도움말(200)은
눌러도 아무 일이 없는데 사용 가능한 버튼처럼 보이므로 계속 경고 후 그리지 않는다.

### HI-SPEED FIX와 선곡 화면 프레임

- SevenMania의 스크롤 시계는 원래 채보의 기준 BPM(`#BASEBPM`, 없으면 시작 BPM)으로 환산한 초 단위다. 그래서 고정이 없어도
  시작 BPM에서는 BPM과 관계없이 같은 속도로 흐른다(LR2의 START 고정과 같다, `#BASEBPM`이 있으면 그 BPM 기준).
- `[Display] HiSpeedFix`(설정 화면 "게임 → HI-SPEED FIX", LR2 버튼 55): 0 끔(기존 동작 그대로), 1 시작 BPM, 2 최대 BPM,
  3 주 BPM(마지막 노트까지 가장 오래 머무는 BPM), 4 최소 BPM — 고른 BPM이 지금의 시작 BPM과 같은 속도로 흐르도록 배속에
  `기준 BPM ÷ 고른 BPM`을 곱한다. 곡 안에서 BPM이 바뀌면 속도도 그만큼 바뀐다(LR2와 같다).
  5 일정 — BPM 변화·정지·`#SCROLL`·`#SPEED`를 무시하고 실제 시간으로 노트를 흘려 곡 전체에서 화면상 노트 속도(녹색 숫자)를
  하나로 유지한다. 속도는 끔 상태의 시작 BPM 속도와 같다. 판정·소리·BGA는 그대로 채보 시간을 따른다.
- 표시 배속(숫자 10, 일시정지 화면)은 사용자가 정한 배속 그대로이고, 곱한 값은 노트·마디선 위치에만 쓴다. 코드는 `src/HiSpeedFix.h`.
- `[Display] SelectFPS`(설정 화면 "화면 → 선곡 화면 프레임"): 60 또는 120. 선곡 화면이 움직이는 동안(LR2 선곡 스킨, BGA 배경,
  긴 제목 흐름 등) 그 주기로 다시 그린다. 이전에는 대기 시간 33ms로 약 30 FPS였다. 플레이 화면의 프레임 목표(`FPS`)와 `FramePacer`에는
  영향을 주지 않는다. 코드는 `src/SelectFrameClock.h`와 `Main.cpp`의 메시지 루프.

### 선곡 바

바에 붙는 요소는 모두 바의 왼쪽 위를 기준으로 한 상대 위치에 그린다.

| 명령 | 동작 |
|---|---|
| `BAR_TITLE` | 스킨 폰트와 위치로 제목을 그린다. 폰트에 없는 글자가 있으면 시스템 글꼴 |
| `BAR_LEVEL` 0~6 | 채보 난이도 번호의 숫자 그림으로 레벨을 그린다. 그 번호가 없으면 0번을 쓴다. 레벨이 숫자가 아니거나 스킨에 `BAR_LEVEL`이 없으면 시스템 글꼴 |
| `BAR_LAMP` 0~5 | 미플레이, 실패, 이지, 노멀, 하드, 풀콤보. 선택한 곡의 옵션 100~105와 같은 기준이며 블렌드(가산)를 따른다 |
| `BAR_RANK` 1~8 | F~AAA. 제목 위에 겹쳐 그린다. LR2처럼 최고 EX 점수 ÷ (노트 수 × 2)를 9등분해 정한다(F < 2/9 ≤ E … AA < 8/9 ≤ AAA). 노트 수는 기록에 저장한 값, 없으면 채보의 노트 수다. `BestExScore`가 없는 옛 기록만 예전처럼 최고 정확도 점수 ÷ 만점으로 대신한다 |
| `BAR_FLASH` | 스킨이 지정한 선택 강조를 현재 바에 그린다 |

- 선택을 옮기면 바가 이웃 칸에서 제자리로 120ms 동안 미끄러진다. 한 번에 여러 칸을 옮겨도 한 칸 거리만
  움직이고, 목록 내용이 바뀐 경우(필터·정렬·폴더 이동)에는 움직이지 않는다. 클릭은 마지막으로 그린 바의 좌표와 행을 사용한다.
- 목록은 순환하지만, 목록 줄 수가 바 칸 수보다 적으면 각 줄을 한 번만 그린다. 선택 바(`BAR_CENTER`)에서 가까운
  칸부터 줄을 배정하고 이미 그린 줄이 다시 나오는 칸은 비운다(예: 줄이 하나면 선택 바 하나만 그린다).
  LR2 원본에서 짧은 목록이 반복 표시되는지는 확인하지 못했다.
- 바 종류는 곡(0)과 폴더(1)만 구분한다. `BAR_MY_LAMP`, `BAR_RIVAL`, `BAR_RIVAL_LAMP`는 라이벌 기능이 없어 읽지 않는다.

### 레벨 그래프와 마우스 반응

- `BARGRAPH`는 선곡 화면의 3(선택한 채보 레벨)과 5~9(같은 곡의 BEGINNER~INSANE 레벨)만 그린다.
  값은 레벨 ÷ 상한(5/10키 9, 7/14키 12, 9키 42)이며 상한을 넘으면 가득 채운다. 방향 0은 오른쪽으로,
  1은 아래로 자라고, 원본 그림도 같은 비율만큼만 잘라 쓴다. 플레이 화면의 그래프(진행도·점수)는 아직 없다.
- "같은 곡의 다른 난이도"는 SevenMania가 한 줄로 묶은 채보들이다. 숫자 45~49가 그 레벨을 표시한다.
- `ONMOUSE`는 커서가 그림 안의 지정 사각형에 있을 때만 그린다. panel 값 -1은 패널이 닫혀 있을 때,
  0은 항상, 1 이상은 그 패널이 열려 있을 때다. 창이 앞에 있을 때만 커서를 읽는다.

### 플레이·결과의 숫자와 타이머

- 랭크는 만점을 27등분한 경계(F < 6 ≤ E < 9 ≤ D < 12 ≤ C < 15 ≤ B < 18 ≤ A < 21 ≤ AA < 24 ≤ AAA)로 정한다.
  "현재 랭크"는 지금까지 판정한 노트만으로, "확정 랭크"는 전체 노트 대비 이미 얻은 점수로 계산한다.
- 추가된 숫자: 76/177(미스 수 = BAD + POOR), 115/116(전체 달성률), 171(EX 점수), 174(최대 콤보), 21~26(시계).
- 타이머 140은 현재 BPM의 한 박 안에서 흐른 시간이다. BPM이 바뀌는 지점에서 박의 시작을 다시 맞추지는 않는다.

### 플레이의 끝과 그래프

- **실패**: 게이지가 바닥나면 스킨의 `#CLOSE` 시간 동안 타이머 3이 흐르고(셔터가 닫히는 연출) 그 뒤 결과로 넘어간다.
  **정상 종료**: 곡이 끝나면 `#FADEOUT` 시간 동안 타이머 2가 흐른다. 스킨에 그 값이 없으면 예전처럼 바로 넘어간다.
  이 동안에는 판정·게이지·입력이 멈추고 화면만 움직인다. 정상 종료는 음악을 끊지 않는다. 실패(게이지 바닥·QUIT)는
  LR2처럼 그 순간 곡을 멈추고 화면을 마지막 시각에 고정한 채 `playstop`을 낸다. 결과 화면의 `fail`은 `playstop`이 끝난 뒤 울린다
  (시스템 효과음 순서는 [SystemSoundFolders](SystemSoundFolders-2026-11-18.md)).
  연습 모드와 무입력 벤치마크에서는 기다리지 않는다. 코드는 `Main.cpp`의 `lr2HoldFinish`.
- **일시정지 QUIT**: 일반 플레이에서 일시정지 메뉴의 QUIT(또는 Q)를 고르면 일시정지를 풀고 게이지가 바닥난 것과
  같은 실패 경로를 탄다. LR2 스킨은 타이머 3과 `#CLOSE`, 기본 스킨은 결과 페이드를 거쳐 결과로 가며 FAILED로 기록되고
  클리어 램프는 오르지 않는다. 그때까지의 판정은 남는다. 연습 모드와 무입력 벤치마크는 예전처럼 선곡으로 바로 돌아간다.
  판정은 `PlayOutcome.h`.
- **풀콤보**: 마지막 노트까지 BAD·POOR 없이 판정하면 타이머 48이 시작된다.
- **`BARGRAPH`**: 1(곡 진행도), 2(로딩, 항상 가득), 10(현재 점수 ÷ 만점), 11(지금 페이스의 최종 달성률),
  12/13(최고 점수의 현재 위치/최종), 14/15(목표 점수의 현재 위치/최종). 크기가 음수이면 반대쪽 끝에서 자란다.
  "현재 위치"는 고스트 기록이 없어 최고·목표 점수에 판정한 노트 비율을 곱한 값이다.
- **최고·목표 점수**: 최고 점수는 채보의 `BestExScore`(이번 플레이 전 기록)다. 목표는 선곡의 타깃 설정을 따른다:
  MY BEST는 최고 점수(기록이 없으면 0), RANK AAA/AA/A는 만점의 8/9·7/9·6/9, DEFAULT는 만점 × 기본 타깃 %이며
  랭크와 비율은 올림한다(목표에 닿으면 그 랭크). 숫자 151은 목표 점수,
  108은 현재 EX 점수 − 목표의 현재 위치 점수(음수를 그리려면 부호 있는 24칸 숫자 이미지가 필요)다.
- **스코어 그래프 옵션**: 39(표시)/38(숨김)은 `keybindings.ini`의 `[LR2Skin] ScoreGraph`(기본 1)를 따른다.
  설정 화면 "스킨" 페이지의 "플레이 스코어 그래프"나 선곡 화면 버튼 70으로 바꾼다. 오토 스크래치 54~57은 SevenMania에 그 기능이 없어 항상 꺼짐(54·56 참)이다.
- **턴테이블 회전**: 내장 오프셋 1(1P)/2(2P)을 단 `DST_*`는 2초에 한 바퀴, 스크래치 레인을 누르는 동안 3배
  빠르게 돈다. 각도는 `DST`의 회전값에 더하고 회전 중심도 그대로 쓴다. 방향 반전(역회전 스크래치)은 구분하지 않는다.
- **`AUTO_*` 노트**: `SRC_AUTO_NOTE`/`LN_*`/`MINE`은 경고 없이 별도 세트로 읽고, 오토플레이 중에는 그 레인의
  일반 노트 대신 쓴다(없는 부분은 일반 노트, LN 몸통은 누르는 중에도 `AUTO_LN_BODY`). 조건 32(오토 아님)/33(오토)도
  플레이와 결과 화면에서 실제 오토플레이 여부를 따른다.
- **`SLIDER`**: 6(곡 위치)과 4/5(1P/2P 레인 커버)를 그린다. 레인 커버 슬라이더는 표시용 커버 비율(0 열림~1 닫힘)만큼
  range를 따라 움직인다. 스킨에 이 슬라이더가 있으면 SevenMania의 자체 커버(검은 사각형)는 그리지 않는다.
  기본 테마와 WMIX_HD는 커버를 노트 뒤에 선언하므로 노트를 가린다(노트 뒤 패스).
- **결과의 `GAUGECHART_1P`**: 플레이 중 256칸으로 기록한 게이지를 선으로 그린다. `DST`의 좌표는 그래프의
  왼쪽 아래, 색은 선 색, 폭은 선 굵기다. 번호 0은 일반 게이지, 1은 하드 게이지일 때만 그린다. 스킨이 준
  시작~끝 시간에 걸쳐 왼쪽부터 드러나고, 중간에 실패하면 거기서 끊긴다. 결과 스킨이 지정돼 있으면
  SevenMania 기본 플레이 스킨을 사용해도 게이지를 기록한다. `GAUGECHART_2P`는 읽지 않는다.
- 결과의 숫자 173(이전 최고 콤보)과 175(최고 콤보와의 차이)는 이번 플레이 전 기록이 있을 때만 그린다.
- 결과의 숫자 150/170(이전 최고 EX 점수)과 152/172(이번 EX 점수에서 이전 최고를 뺀 값)는 채보의
  `BestExScore` 기록이 있을 때 그린다. 기존 정확도 점수는 그대로 보존한다. EX 점수는 LR2 스킨 사용 여부와
  관계없이 새 플레이에서 기록하며, 첫 EX 기록을 세우는 결과 화면에서는 이전 값이 없으므로 비교를 표시하지 않는다.
  음수 차이를 그리려면 부호를 포함한 24칸 숫자 이미지가 필요하다.
- 결과의 목표(MY BEST) 숫자 120~134와 이전 최소 미스 176은 이번 플레이 전 기록에서 가져온다. 120은 최고 정확도
  점수 ÷ 5(LR2 점수 단위), 121~123은 `BestExScore`와 그 달성률, 125는 이전 최대 콤보, 126은 노트 수,
  130~134는 `BestJudgements`, 176은 `MinMissCount`다. 기록에 없는 값과 이 채보의 노트 수를 넘는 값은 그리지 않는다.
  177(이번 미스)은 이번 BD+PR이다. 179·180(IR)은 기능이 없어 경고로 남는다.

### 기록 항목 (`BmsPlayer-records.ini`)

채보마다 `Play_<해시>` 구역 하나에 저장한다. 아래 항목은 이후 추가된 것으로, 이전 형식의 구역에는 없으며
없거나 형식이 틀린 값은 "미기록"으로 읽고 다시 쓰지 않는다. 기존 항목(`Played`, `Cleared`, `MaxCombo`,
`AccuracyScore`, 판정 출처, 분류된 클리어 램프와 `LegacyClearUnknown`)은 그대로 보존한다.

| 키 | 뜻 | 갱신 규칙 |
|---|---|---|
| `BestExScore` | 최고 EX 점수 | 더 높을 때 |
| `BestJudgements` | `PG,GR,GD,BD,PR` | `BestExScore`를 세운 플레이의 값. 같은 점수는 판정이 미기록일 때만 채운다 |
| `MinMissCount` | 최소 BD+PR. 실패·중단한 플레이는 도달하지 못한 노트도 미스로 센다 | 더 낮을 때 |
| `PlayCount` / `ClearCount` | 플레이·클리어 횟수(연습 모드와 진단 실행 제외) | 매 플레이 |
| `TotalJudgements` | 그 채보에서 지금까지 낸 `PG,GR,GD,BD,PR`의 합(선곡 숫자 33~37) | 매 플레이에 더한다 |
| `NoteCount` | 마지막 플레이 때 채보의 판정 노트 수 | 매 플레이 |

이전 형식의 기록은 이 항목들이 생긴 뒤의 플레이부터 센다(그 전의 플레이 횟수와 판정은 알 수 없다).
판정 수는 LR2 스킨 사용 여부와 관계없이 `ResultScore`가 센다. 롱노트는 머리와 끝 반 단위를 합쳐 한 노트다.
- 결과 화면의 입력과 타이머는 아래 "결정·결과 화면의 시계"를 따른다. `SCENETIME`이 양수면 시간이 지나면
  자동으로 복귀를 시작한다. `FADEOUT` 동안 타이머 2 레이어를 그리고 그 뒤 선곡으로 이동한다.

  Next 버튼은 SevenMania 결과 화면에서만 표시한다.

### 키 모드

- 플레이 스킨은 채보의 키 모드로 고른다. 7KEY·5KEY·14KEY·10KEY·9KEY(PMS) 채보가 각각 같은 이름의 슬롯

### 장면 명령

- `FONT`(크기, 굵기, 종류, 글꼴 이름…): 순서대로 기억한다. `SRC_TEXT`의 글꼴 번호에 해당하는 `LR2FONT`가 없거나
  읽지 못하면 같은 번호의 `FONT`에서 설치된 첫 글꼴 이름과 굵기(DX Library 0~9, 기본 6)를 쓴다. 없으면 Segoe UI.
  LR2가 두 목록을 하나로 세는지는 확인하지 못해 번호는 `LR2FONT` 기준을 유지한다.
- `STARTINPUT`(선곡·플레이): 화면이 처음 그려진 뒤 그 시간 동안 입력을 받지 않는다. 선곡은 키·클릭·휠을 모두
  버리고(선곡 화면에 돌아올 때마다 다시 센다), 플레이는 로딩 중의 Esc(취소)·Enter(인트로 건너뛰기)를 버린다.
  결정·결과의 `STARTINPUT`은 아래 "결정·결과 화면의 시계"와 같다. 판단은 `Lr2ScreenState.h`의 `sceneInputLocked`.
- `SKIP`(곡 결정): 그 시간(과 `STARTINPUT`)이 지난 뒤 Enter를 누르면 타이머 3을 시작하고 `FADEOUT` 뒤 로딩/플레이로 넘어간다(위 "결정·결과 화면의 시계").
- `LOADSTART`/`LOADEND`/`PLAYSTART`(플레이): 곡 시작 전 진행을 정한다(아래 "플레이 시작 전").
- `SCRATCHSIDE`(플레이): 경고 없이 읽어 접근자로 노출한다. 레인 배치는 `DST_NOTE` 위치가 정하므로 쓰지 않는다.

### 플레이 시작 전

결정 화면이 끝나면 차트를 읽는 동안 LR2 플레이 스킨을 바로 그린다(이전에는 곡 시작까지 검은 화면). 계산은
`src/skin/lr2/Lr2PlayTimeline.h`의 `playLeadIn`, 호스트 연결은 `presentLr2PlayLeadIn`(`SongIntroHost.inl`)과
`pollPreparingPlayback`(`PlaybackLoadRuntime.inl`)이다.

1. 스킨이 처음 그려진 순간 타이머 0(씬)이 시작된다.
2. 로딩 중에는 옵션 80이 참, 81이 거짓이다. 바 그래프 2(로딩 진행)는 `LOADSTART`부터 `LOADEND` 동안 0→1로 차는데,
   실제 로딩이 끝나기 전에는 0.99에서 멈춘다.
3. 실제 로딩과 `LOADSTART`+`LOADEND`가 둘 다 끝나면 READY(타이머 40)가 시작되고 옵션 81이 참이 된다.
4. READY 뒤 `PLAYSTART`가 지나면 곡을 시작한다(타이머 41과 노트·음악).
   곡이 시작돼도 타이머 0과 40은 끊기지 않고 이어진다.

- LR2 스킨이 없거나 GPU 출력에 실패하면 이전처럼 준비 후 3초 대기로 시작한다. 미리보기 요청은 즉시 시작한다.
- 재시작(F5)은 곡 자체에서 다시 시작하며 타이머 0·40·41이 함께 0부터 다시 간다.
- 로딩 파이프라인의 generation과 취소 검사는 그대로다. 화면은 작업이 적용된(`applied`) 뒤에만 그린다.

### 레인 커버(레인 가드) 연출

- 로딩 중 레인을 덮었다가 READY에 올라가는 연출은 스킨이 정한다. 예: WMIX_HD `wide_1p.csv`의 조건 954는 로딩 중(옵션 80)
  커버 그림을 타이머 0으로 내리고, 로딩이 끝나면 `SLIDER` 4가 타이머 40으로 1초간 올라간다. 이전에는 `SLIDER` 4를
  그리지 않아 로딩이 끝나는 순간 커버가 사라졌다.
- 커버는 사용자 설정 위치에서 멈춘다. 마지막 노트를 판정하고(롱노트로 끝나면 꼬리까지, 눌린 홀드가 없을 때)
  500ms 뒤부터 부드럽게 끝까지 내려온다. 걸리는 시간은 스킨 `FADEOUT`의 절반(200~800ms)이다.
- `FADEOUT`(정상 종료)·`CLOSE`(실패)·일시정지 QUIT이 그보다 먼저 시작되면 그 순간부터 닫는다. 실패와 QUIT은
  이전처럼 즉시 닫히며 스킨의 셔터(타이머 3)와 같은 구간에 겹친다. 실패는 노트가 남아 있어도 끝나는 상황이라
  "마지막 노트" 기준이 없고, QUIT은 사용자가 바로 나가려는 것이어서 기다리게 하지 않았다.
- 커버는 화면 표시만 바꾼다. 곡의 끝(남은 키음·BGM)과 `FADEOUT`·결과 화면 전환 시점은 그대로다.
  연습 모드처럼 전체 노트를 다 치지 않는 경우에는 종료 연출 시작 시점 기준만 쓴다.
- 이 움직임은 표시용 값(`PlayFrame::laneCoverShare`, `laneCoverDisplay`)만 바꾼다. 저장된 레인 커버 설정과 옵션
  46/50·숫자 14가 보는 `laneCover`는 그대로다. 커버 슬라이더가 없는 LR2 스킨은 자체 커버가 같은 방식으로 내려온다.
- SevenMania 기본 스킨에는 적용하지 않았다. 곡이 끝나면 곧바로 결과 페이드로 넘어가 커버가 움직일 종료 구간이 없고,
  시작 시 커버를 올리는 연출을 넣으면 첫 노트가 가려질 수 있어서다.
- `ENDOFHEADER`는 의미가 없는 표시로 보고 경고 없이 넘긴다.

- 900~999는 스킨의 번호(`#CUSTOMOPTION`, `#SETOPTION`)다. 한 번도 정해지지 않은 번호는 다른 미지의 ID처럼 거짓(부정해도 거짓)이지만,
  플레이어의 빈틈이 아니므로 "Unknown condition ID" 경고를 남기지 않는다. 예: 결정 화면의 `#SETOPTION,990`이 실행되지 않은 경우.

선곡 화면의 조건 110~117(최고 기록 랭크 AAA~F)은 `BAR_RANK`와 같은 EX 점수 랭크로 답한다. 고르지 않은
`#CUSTOMOPTION`은 첫 선택지로 보고 나머지 ID는 거짓으로 둔다(호출자가 지정한 값은 그대로).
선곡 전용: `BAR_MY_LAMP`, `BAR_RIVAL*`(라이벌), `README`(곡 폴더의 텍스트 보기), `HELPFILE`, `RELOADBANNER`.

- `MOUSECURSOR`(선곡): 커서 위치에 `DST`의 x·y만큼 떨어뜨려 그린다. 이 레이어가 있으면 창 안에서 시스템 커서를 숨긴다.
  그림을 읽지 못해 레이어가 빠지면 시스템 커서를 그대로 쓴다.

## 글자

- `LR2FONT`가 가리키는 비트맵 폰트(`.lr2font`와 글리프 시트)를 읽어 `SRC_TEXT`와 `SRC_BAR_TITLE`에 쓴다.
  폰트 번호는 `LR2FONT` 선언 순서다. 코드는 `src/skin/lr2/Lr2Font.h`.
- `<폴더>\font.lr2font`가 디스크에 없으면 같은 위치의 `<폴더>.dxa`에서 꺼낸다. LR2 기본 테마의 폰트가
  이 형태다. DX Library 보관 파일 버전 3, 기본 키만 읽으며 폰트 외의 용도(이미지 등)로는 쓰지 않는다.
- 글자 크기는 `DST`의 size ÷ 폰트 크기, 글자 간격은 글리프 폭 + 폰트의 margin이다. 정렬 기준점은
  0 왼쪽, 1 가운데, 2 오른쪽이고, 상자 폭보다 긴 글은 LR2처럼 가로로 좁혀 넣는다. `DST`의 색을 곱한다.
- LR2 폰트는 Shift_JIS 범위의 글자만 가진다. 한글처럼 폰트에 없는 글자가 하나라도 있으면 그 문자열
  전체를 시스템 글꼴(Segoe UI)로 그린다. 폰트를 읽지 못했을 때도 같다.
- 글리프 시트는 그 글자를 처음 그릴 때 올린다. 한 화면에서 96장을 넘으면 모두 비우고 다시 채운다.
- 텍스트 참조는 10~16(제목, 부제, 전체 제목, 장르, 아티스트, 부아티스트, 전체 아티스트)과 선곡 화면의 옵션 이름(1, 60, 63~68,
  70~76, 79, 80, 84, 85, 위 "옵션 패널")만 지원한다. 그 밖의 참조는 경고 없이 그리지 않는다.

## 알려진 구조적 한계

- `IF`는 중첩된다. 안쪽 블록은 바깥 블록이 참일 때만 조건을 평가하고, 거짓인 블록 안의 `IF`/`ELSE`는
  통째로 건너뛴다. `ENDIF`는 자기 블록만 닫는다. `INCLUDE`된 파일은 바깥 파일과 조건 상태를 공유하므로
  포함된 CSV의 `ENDIF`가 바깥 `IF`를 닫을 수 있고, 닫지 않은 `IF`는 이후 내용에 이어진다. 짝이 맞지 않는
  조건문은 경고만 남기고(`Unclosed IF`는 메인 파일 끝에서 한 번), 로드를 멈추지 않는다.
- `INCLUDE`/`IMAGE` 와일드카드는 파일명의 `*` 하나만 지원한다. `CUSTOMFILE` 기본값이 우선이고,
  없으면 이름순 첫 파일을 쓴다(LR2의 무작위 선택과 다름). `패턴|a|b`처럼 `|` 뒤에 적은 문자열을 이름에
  포함한 파일은 후보에서 뺀다(대소문자 무시). `CUSTOMFILE` 패턴과 설정 화면의 선택지에도 같은 규칙을 쓴다.
- `DST_*`의 오프셋 ID는 스킨이 `CUSTOMOFFSET`으로 선언한 것과 플레이의 턴테이블 회전(1/2)만 적용한다.
  그 밖에 게임 상태로 움직이는 내장 오프셋은 경고만 남긴다. 노트(`DST_NOTE`)와 선곡 바 위치에는 적용하지 않는다.
- 조건(옵션) 대부분은 로드 시점에 한 번 평가한다. 프레임마다 바뀌는 것은 플레이의
  `PlayFrame::option` 목록과 선곡의 `SelectFrame::option` 목록(위 "선곡 화면의 조건")뿐이다.
  `IF` 블록 전체를 매 프레임 재평가하는 것은 하지 않기로 했다. `IF`는 `IMAGE`·`INCLUDE`·`LR2FONT` 선언과
  레이어 목록 자체를 바꾸므로, 재평가하려면 조건이 바뀔 때마다 이미지 디코드·GPU 업로드·레이어 재구성을
  다시 해야 해서 프레임 예산에 맞지 않는다(측정은 하지 않았다). 대신 `DST_*`의 조건처럼 레이어 단위로 매 프레임 확인하는 ID를
  `option` 목록에 늘리는 쪽이 비용이 작다.
- 게임은 `.lr2skin`이 직접 참조하는 활성 `INCLUDE` 누락을 로드 실패로 처리한다. CSV 안의 하위
  `INCLUDE`가 누락되면 경고를 남기고 나머지를 읽는다. 필수 레인이나 선곡 바가 구성되지 않으면 기본 스킨으로 복귀한다.
- 활성 `RESOLUTION`은 메인 파일과 포함된 CSV에서 읽는다. 선언이 없으면 원점에서 시작하는
  `DST_IMAGE`의 크기가 SD·HD·FHD·4K 중 하나로 일치할 때 원본 해상도를 판별한다. 후보가 여러 개면 SD를 사용한다.
- 설정 페이지에 사전 검사 및 실제 실행 중 오류를 구분해 표시한다. 실행 중 오류는 디버그 출력에도 남긴다.
- GPU 로드에 실패하면 화면을 기본 스킨으로 전환한다. 선곡 화면에 다시 진입하거나 플레이를 재시작하면 유지한 씬의 GPU 리소스를 다시 준비한다. 씬의 이미지·폰트·현재 배너 CPU 픽셀은 GPU 리소스와 별개로 관리한다.

## 스킨별 선택값

`%APPDATA%\BmsPlayer\lr2-skins.txt`(설정 파일과 같은 폴더, UTF-8)에 스킨 파일마다 한 구역으로 저장한다.
구분자는 탭이다. 이름은 스킨 헤더에 적힌 그대로이며 `--report`가 목록을 출력한다.

```
[c:/games/lr2files/theme/x/play_7.lr2skin]
option	Scratch Side	Right
file	LANE COVER	black
offset	Judge Position	0,-20,0,0,0,0
```

- `option`: 선택지 이름. 고르면 그 옵션 묶음의 모든 ID가 참/거짓으로 확정되며 호스트 기본값보다 우선한다.
- `file`: 패턴의 `*` 자리에 들어갈 파일명. 그 파일이 없으면 스킨 기본값, 그것도 없으면 이름순 첫 파일.
- `offset`: x, y, w, h, 회전, 알파. 스킨이 허용하지 않은 성분은 0으로 처리한다. 값은 해당 오브젝트의
  모든 키프레임에 더해진다.
- 스킨에 없는 이름이나 선택지는 무시한다. 읽기·쓰기는 `src/skin/lr2/Lr2SkinConfig.h`가 맡는다.
  설정 화면이 `option`·`file`·`offset` 줄을 모두 쓴다. 직접 적은 `offset` 줄도 그대로 읽는다.

## 설정 화면

게임 설정(RmlUi)의 "스킨" 페이지에 있다. 코드는 `src/Lr2SkinSettings.inl`, 폴더 검색은
`src/skin/lr2/Lr2SkinLibrary.h`다.

- **자동 검색 폴더**: 게임 실행 파일 옆의 `Theme`. 스킨 폴더를 통째로 넣고 스킨 탭을 열면 하위의
  `.lr2skin` 헤더를 검색해 화면 종류별로 나눈다. 탭을 다시 열거나 **다시 검색**을 눌러 목록을 갱신한다.
- **화면별 스킨**: 선곡, 곡 시작, 7KEY·5KEY·14KEY·10KEY·9KEY 플레이, 결과. "사용 안 함"이면 그 화면은 SevenMania 스킨을 쓴다.
  저장된 파일이 사라졌으면 그 화면만 SevenMania 스킨으로 돌아간다.
- **스킨 옵션**: 지정한 스킨 하나를 골라 `CUSTOMOPTION` 선택지와 `CUSTOMFILE` 파일, `CUSTOMOFFSET` 값을 바꾼다.
  오프셋은 "오프셋 · 이름 · X"처럼 스킨이 켠 칸마다 항목이 하나씩 있고, 고르면 "오프셋 값" 슬라이더가 나타난다
  (x·y·w·h ±640, 회전 ±360, 투명도 ±255). 값을 바꾸면 바로 저장되고 다음에 그 화면을 그릴 때 적용된다.
- **플레이 스코어 그래프**: 옵션 39(표시)/38(숨김). 설정 파일의 `[LR2Skin] ScoreGraph`에 저장되며 다음 플레이부터 적용된다.
- 화면별 선택은 설정 파일의 `[LR2Skin]` 구역(`Select`, `Decide`, `Play7`, `Play5`, `Play14`, `Play10`, `Play9`, `Result`)에 저장된다.
  기존에 지정한 파일이 여전히 있으면 해당 화면에서 계속 사용한다. 예전 `Root` 값은 새 스킨 검색에 사용하지 않는다.
  선곡 스킨은 설정을 닫을 때, 나머지는 다음 곡 시작부터 반영된다.
- 플레이·로딩·결과 화면 중에는 바꿀 수 없고, 명령줄로 스킨을 지정한 실행에서는 표시만 한다.
- 스킨을 지정하면 GPU 없이 한 번 불러 보고, 그릴 수 없으면 화면 이름과 사유(예: 찾지 못한 INCLUDE)를
  페이지 아래에 표시한다. 그 화면은 SevenMania 스킨으로 나온다.
- 네이티브(RmlUi 없는) 설정 화면에는 이 항목이 없다. 그 빌드에서는 저장된 값만 적용된다.

## 진단 도구

- `--report`: 위 표의 형식으로 종류별 경고 수와 ID 목록을 출력한다. 종료 코드는 씬 로드 성공 여부다.
- `--lr2-preview` 창의 F1: 같은 요약을 먼저 보여 주고 이어서 앞쪽 경고 30줄을 보여 준다.
- 집계 규칙은 `src/skin/lr2/Lr2Diagnostics.h`에 있다. 끝의 숫자나 `: ` 뒤의 이름을 떼어 종류별로 묶는다.

  턴테이블 회전, 콤보가 실제 입력처럼 움직인다. 스크래치와 2P 쪽 레인도 같다.
  - 단노트는 80 ms 누른 뒤 떼되, 같은 레인의 다음 노트와 그 레인의 다음 지뢰보다 먼저(지뢰 2 ms 전) 뗀다.
  - 롱노트(LN/CN/HCN)는 머리에서 눌러 꼬리에서 뗀다. CN의 뗌도 PGREAT, HCN은 몸통 내내 누르고 있다.
  - 지뢰는 키를 떼어 피한다. 롱노트 몸통 안이나 노트와 같은 시각의 지뢰처럼 피할 수 없는 것은 오토플레이 중 무시한다.
  - 오토플레이 중에는 플레이어의 레인 입력(키보드·컨트롤러)을 받지 않는다. 창이 포커스를 잃어 일시정지돼도 오토가 누르던
    키는 그대로이므로, 다시 이어 해도 롱노트가 끊기지 않는다. 자동 판정 보정(학습·제안)과 타이밍 힌트는 쓰지 않는다.
- **기록**: 연습·무입력 벤치마크·게이지 호환 시험과 같은 규칙(`bms::playSavesRecord`, `src/PlayOutcome.h`)으로
  최고 점수·클리어 램프·플레이 횟수·EX 점수를 저장하지 않는다. 선곡 화면의 전체 플레이 통계에도 들어가지 않는다.
  일시정지의 QUIT은 연습처럼 바로 선곡으로 돌아간다(실패 기록 없음).
- **표시**: 결과 화면은 평소처럼 나오고, 클리어 종류 자리(`ResultClearType` 바인딩과 GDI 대체 화면)에 `AUTO PLAY`를 쓴다.
  SevenMania 기본 스킨으로 플레이하는 동안에는 왼쪽 위에 `AUTO PLAY · 기록되지 않음` 표시가 붙는다. LR2 플레이 스킨은
  조건 33과 `AUTO_*` 노트로 스스로 표시하므로 그 표시를 덧그리지 않는다.
- LR2 레인 커버 연출(마지막 판정 0.5초 뒤 닫힘)과 `#FADEOUT`/`#CLOSE` 종료 연출은 일반 플레이와 같다.
