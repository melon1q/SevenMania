# 곡 선택 / 플레이 아이콘 배치 동기화

각 화면의 아이콘 영역 위치와 곡 선택 화면의 표시 배율은 유지한다.
내부 순서는 플레이 화면처럼 **배속 → 게이지 → 판정**으로 통일한다.
클릭 기능의 의미는 기존 ID대로 유지한다 (`slot-0` 배속, `slot-1` 판정,
`slot-2` 게이지). 화면에 보이는 순서를 바꿔도 클릭 동작이 바뀌지 않는다.

`SelectionSlotLayout.h`에서 플레이 화면의 이미지 및 텍스트 배치를 읽어
곡 선택 영역의 크기에 비례시킨다. 이미지 리소스, 텍스트 상대 좌표/크기,
위치와 크기를 공통 기준으로 맞춘다. 글꼴·글자 크기·정렬·색상·투명도는
각 화면에서 편집한 값을 유지하며 플레이 화면 값으로 덮어쓰지 않는다. 기본 스킨의 플레이 세 번째
아이콘에는 판정 모드 값과 JUDGE 라벨을 추가했다.

`play.judgementProfile` 바인딩은 현재 게임 설정의 BASIC/EASY/NORMAL/HARD를
읽기 전용으로 제공한다. 판정 계산 규칙이나 입력 동작은 수정하지 않는다.

런타임에서는 스킨 로딩 시 한 번 동기화하고, 에디터에서는 같은 함수를 사용해
미리보기와 저장할 곡 선택 레이어를 갱신한다. 따라서 플레이 아이콘 이미지를
교체하거나 배치를 수정하면 곡 선택 화면에도 반영된다. 공통 기준 요소가 없는
부분/기타 스킨은 이 동기화를 생략한다. 개별 텍스처를 프레임마다 읽지 않는다.

기본 패키지와 템플릿 생성기도 갱신했다. 소수 크기 비율은 유지하되 글자 크기는
스킨 규격에 맞게 정수로 반올림한다.

검증: 스킨 관련 CTest 8개 통과. 순서, 이미지 일치, 이미지 교체 전파,
텍스트 정렬, 기존 클릭 동작, 바인딩, 저장/재로딩, 에디터 smoke를 포함한다.
기본 BmsPlayer.exe와 SevenManiaSkinEditor.exe의 Release 빌드에 반영했다.
