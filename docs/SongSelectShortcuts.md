# 곡 선택 화면 빠른 설정

- 배속, 판정, 게이지 아이콘은 왼쪽 클릭으로 증가, 오른쪽 클릭으로 감소한다.
- 기존 설정 범위와 저장 방식을 유지한다. 배속 범위는 0.50x~10.00x다.
- 스킨 표시값을 읽기 전용 문자열 바인딩 `select.speedText`, `select.judgementText`, `select.gaugeMode`에 연결한다. 곡이 선택되지 않아도 설정값을 제공한다.
- 기본 템플릿의 배속은 `hud-hi-speed.png`, 게이지는 `hud-gauge-mode.png`, 나머지는 `hud-icon-slot.png`를 사용한다.
- 기존 기본 템플릿을 편집한 스킨의 `slot-value-0..2` 고정값은 로딩 중 메모리에서만 바인딩으로 연결한다. 명시적으로 지정한 바인딩은 유지한다.
- 기존 `slot-0`, `slot-2`가 공통 slot 이미지를 쓰고 전용 리소스를 포함하면 메모리에서 전용 이미지로 연결하고 중복 제목을 숨긴다. 원본 스킨 파일과 사용자 디자인은 다시 저장하지 않는다.
- 클릭 판정은 스킨의 `slot-0..2` 배치와 화면의 contain 배율/여백, 요소 회전 및 clip을 사용한다. 스킨 없는 경로에서는 기존 배치로 처리한다.
- 값이 바뀌면 기존 스냅샷/텍스트 캐시 갱신으로 화면에 반영한다. 변경 없는 프레임에는 텍스트를 다시 생성하지 않는다.

검증: 실제 창 메시지의 좌/우 클릭, 설정 저장, 세 바인딩 값, 스킨 화면 갱신을 확인한다. 1920×1080, 1280×720, 1024×768, 2560×1440의 클릭 좌표를 검증한다. 기존 바인딩/스킨 적용 회귀 테스트도 실행한다.
