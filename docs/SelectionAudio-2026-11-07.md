# 준비 노트 및 선곡 오디오 (2026-11-07)

준비 화면의 첫 노트 그룹은 Ctrl을 누르는 동안만 그린다. 레인·판정선과 설정 조작, 실제 채보와 독립된 프리뷰 타이머는 유지한다.

실행 파일 기준 Assets/decide.mp3는 곡 실행을 확정한 뒤 진입할 때 재생한다. 기존 AudioEngine을 별도 인스턴스로 재사용하여 채보 PCM 준비 중 releaseSong에 잘리지 않게 한다. 출력 음량은 마스터·효과음 설정을 따른다. 파일이 없거나 디코딩하지 못하면 재생하지 않는다.

Assets/select.mp3는 선곡 화면 배경음으로 반복 재생한다. 기존 SongPreview의 비동기 디코딩·캐시·반복 재생을 재사용한다. 마스터 및 노래 음량 설정을 따르고, 곡 프리뷰가 실제 재생 중이면 노래 음량을 5%로 제한한다. 사용자가 5%보다 낮게 설정했으면 음량을 올리지 않는다. 곡을 바꾸면 프리뷰가 정지되므로 배경음 음량은 원래 설정으로 복원되며, 배경음 재생 위치는 유지된다. 플레이 진입 시 배경음은 정지한다.

파일은 시작 시 확인한다. 나중에 준비한 파일은 Release/Assets에 넣고 재실행하면 된다. 소스 Assets에 넣으면 이후 빌드가 Release/Assets로 선택적으로 복사한다. 파일 누락은 빌드 실패 사유가 아니며 다른 파일로 대체하지 않는다. 배경음 파일이 없으면 추가 디코딩 작업 스레드도 시작하지 않는다.

Release BmsPlayer 빌드 성공. BmsAudioTests --selection-policy에서 101개 음량/감소/복원 정책 및 선택 파일 누락 경로 통과. 실제 MP3 파일과 게임 청취 검증은 수행하지 않았다. 기본 스킨은 빌드 전후 바이트 동일성을 확인하고 보존했다.
