# 여러 곡 한 번에 추가하기

곡 선택 화면에서 **F2**를 누른다.

- **여러 곡 폴더**: Ctrl 또는 Shift를 누르고 폴더들을 선택한 뒤 **곡 추가**를 누른다.
- **여러 채보 파일**: 선택 창 아래 **채보 파일 선택...**을 눌러 파일 모드로 바꾼다. Ctrl 또는 Shift로 여러 파일을 선택하고 **곡 추가**를 누른다. **곡 폴더 선택...**으로 되돌아갈 수 있다.
- 지원하는 채보 확장자: `.bms`, `.bme`, `.bml`, `.pms`, `.bmson`, `.mbm`.

채보를 직접 선택해도 음원·이미지 등 동반 리소스가 빠지지 않도록 **채보가 들어 있는 폴더 전체**를 기존과 같은 방식으로 `Songs`에 가져온다. 해당 폴더의 다른 난이도 채보도 함께 추가된다. 원본 파일은 이동하거나 삭제하지 않는다. ZIP 파일을 직접 가져오는 기능은 포함하지 않는다.

같은 곡 폴더의 채보를 여러 개 선택하거나 상위·하위 폴더를 동시에 선택하면 겹치는 복사를 생략한다. 기존 곡은 유지하고, 변경 없는 파일은 기존 가져오기 정책에 따라 재사용한다. 선택 항목을 모두 처리한 뒤 라이브러리를 한 번 검색한다.

잘못된 항목이나 복사 실패가 있으면 나머지 항목은 계속 처리하고, 완료 상태에 실패 개수와 첫 번째 오류를 표시한다. 취소하면 진행 중인 새 곡 폴더의 임시 복사본을 정리하며, 이미 완료된 곡은 유지한다.
